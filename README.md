# 병동 근무표 및 호실 배정 시스템

브라우저에서 실행되는 정적 웹앱입니다. 서버, Python, 외부 JavaScript 라이브러리 또는 최적화 엔진을 사용하지 않습니다.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 주요 기능

- 근무표 자동 생성 및 수동 수정 검증
- D/E/N, OFF, 연차, M 배정
- 오프 신청, 잔여 연차, 고정 셀, 이전 근무 이력 반영
- 호실 앞/중/뒤 및 7A/7B 배정
- 간호사별 통계와 법적 검증 항목 표시
- 설정 저장과 JSON 백업/복원
- Excel 호환 `.xls` 내보내기
- 근무표 및 호실표 PNG 내보내기
- 데스크톱 사이드바와 모바일 하단 탐색

모든 설정과 배정 데이터는 브라우저의 `localStorage`에 저장됩니다.
